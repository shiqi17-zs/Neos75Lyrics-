# 键盘屏幕 HID 协议速记

## 设备

| 用途 | VID:PID | 说明 |
| --- | --- | --- |
| 屏幕数据 / 控制 | `5542:0001` | HID 报告，usage page `0xFF60` / usage `0x61` |
| DFU（刷机） | `5542:1000` | 仅引导模式出现 |
| 2.4G 接收器 | `6D66:8572` | 有同名 HID 接口，但只回显，不转发屏幕数据 |

## 图片推送

* 报告长度 65 字节（1 字节前导 + 64 字节数据）
* 按 4096 字节分块，每块后附 CRC32；设备逐块 ACK
* 帧头声明 JPEG 长度，屏幕解码到 480×360
* 实测吞吐：小帧约 29 KB/s，含分块确认时约 10 KB/s；一帧歌词 0.5~1.2 秒

## 状态查询

* `0x14` 取设备信息：宽、高、是否支持 JPEG、可用空间
* `0x10` 取容量
